# 驗證與完成條件

按本遊戲需求選測試，不為不存在的機制建立形式測試。

## 數學與狀態

- 根據人工可推導或規格提供的 fixture 驗證邊界：不勝、各種勝、wild/scatter、乘倍順序、下注與金額單位、封頂及特殊遊戲進出。
- Expected value 不應直接呼叫被測引擎產生，避免自我驗證。
- 小模型可窮舉；模擬報告記錄規則版本、seed、樣本量、投注/派彩金額與不確定性。樣本 RTP 接近目標不代表已證明正式 RTP。
- 檢查盤面範圍、餘額守恆、局數非負、非法轉移拒絕及完整局程可結束。只對有明確有界規則的機制斷言步數上限。

## Server 故障與帳務

實際測試重複與併發請求、同 ID 不同 payload、餘額不足、過期序號、結算後回應前中斷、重啟後查詢/重送、特殊遊戲中恢復。確認不重扣、不重抽、不重派。
外部錢包 adapter 用可控失敗驗證重試/對帳；只有 mock 通過時不能標記真實錢包已整合。

## 整合與演出

從 client 到真實本機 server 執行一回合，檢查畫面盤面、wins、餘額及特殊狀態與回應一致。執行連點、快速模式/跳過、斷線、重整與重新連線。
Cocos 需檢查場景載入、資產缺失、序列化引用、事件配對、動畫 callback 與離場清理。無法取得編輯器時明列未驗證，不以 TypeScript 編譯取代。

## 紀錄

交付實際啟動文件、環境範例與可重現步驟。若仍欠正式數學、素材、引擎或平台，標示當前可用範圍與阻礙，保留 `TASKS.md` 下一步，不標記完整遊戲完成。
